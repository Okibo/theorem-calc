The standard quadratic formula is used to find the roots of a quadratic equation:

x = [-b ± √(b²-4ac)] / 2a

1. Substitute values: We substitute a=2, b=5, and c=-3 into the formula.

x = [-(5) ± √((5)² - 4 * (2) * (-3))] / (2 * 2)

2. Calculate the discriminant (b²-4ac): This value determines the nature of the roots.

Δ = 25 - (-24) = 49

3. Solve for x: Now we calculate the two possible values for x.

x = [-5 ± √49] / 4 = [-5 ± 7] / 4

This gives us the two roots:

x₁ = (-5 + 7) / 4 = 2/4 = 0.5
x₂ = (-5 - 7) / 4 = -12/4 = -3
